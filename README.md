## О проекте

**Мульти-Пульти 2.0** — это браузерная творческая студия для покадровой мультипликации и детского творчества. Пользователь рисует на холсте HTML5 Canvas, организует слои и объекты (текст, стикеры, растровые штрихи), проигрывает результат с настраиваемой частотой кадров (FPS) и экспортирует мультфильмы в форматы PNG и GIF.

Приложение полностью клиентское (Serverless/Local-first). Все данные проектов надёжно сохраняются в браузере через **IndexedDB** с асинхронной очередью автосохранения и защитой от переполнения квоты, а при первом запуске автоматически и безопасно мигрируют из устаревшего `localStorage`.

## Возможности

### 🎨 Рисование и инструменты
- **Кисть и ластик** с удобным выбором толщины штриха.
- **Заливка (Flood Fill)** замкнутых контуров с порогом толерантности.
- **Пипетка** для быстрого захвата цвета прямо с холста.
- **Симметрия** по горизонтальной оси для рисования бабочек, лиц и узоров.
- **Умный контур (Smart Shape)**: автоматическое распознавание нарисованных от руки кругов, эллипсов и прямых линий.
- **Геометрические фигуры**: прямая линия, круг, прямоугольник.

### 🌈 Палитра и цвета
- Быстрые яркие базовые цвета детской палитры.
- Избранные цвета с сохранением предпочтений.
- История последних использованных цветов (до 8 слотов).
- Полноценный HSV-модал для тонкого выбора любого оттенка.
- Перекраска выделенных объектов и растровых элементов на лету.

### ✨ Редактируемые объекты и выделение
- **Текстовые надписи**: выбор детских шрифтов (Nunito, Caveat, Comic Sans), масштабирование, перемещение и редактирование текста кликом.
- **Стикеры**: эмодзи-наклейки по категориям (животные, еда, эмоции, магия).
- **Прямоугольное выделение**: перемещение, масштабирование, горизонтальное отражение (flip), перекраска и удаление растровых фрагментов с сохранением порядка отрисовки.

### 🎬 Покадровая анимация и таймлайн
- Создание, дублирование (глубокое клонирование), удаление и drag-and-drop перестановка кадров по стабильным UUID.
- Интерактивный предпросмотр с частотой 2, 4, 8, 12 или 24 кадра в секунду (FPS).
- Изоляция кадров: объекты одного кадра гарантированно не утекают в соседние при переключении, воспроизведении или очистке.

### 💾 Сохранение, импорт и экспорт
- **PNG-экспорт**: скачивание текущего чистого кадра без временных оверлеев.
- **GIF-экспорт**: генерация анимированного GIF через Web API с индикатором прогресса и отзывчивым UI.
- **Импорт изображений**: валидация MIME-типа, лимит размера (15 МБ) и разрешения (до 8192×8192), пропорциональное вписывание с сохранением aspect ratio (800×600) и проверка модерацией.
- **Надёжная персистентность**: хранение в IndexedDB, строгая валидация схемы данных, атомарные транзакции и дебоунс-очередь сохранения.

### 🛡️ Локальный эвристический фильтр содержимого
Встроен легковесный эвристический фильтр безопасности, работающий исключительно локально на клиенте (без отправки данных на сервер). Фильтр анализирует пиксели зафиксированного кадра (committed Frame) по совокупности признаков:
- Преобладание агрессивной палитры (только чёрный и красный цвет);
- Длинные диагональные X-образные пересечения тонких линий;
- Хаотичная плотная штриховка;
- Симметричные тонко-штриховые фигуры.

> [!NOTE]
> Фильтр является эвристическим предохранителем, а не абсолютной системой модерации. Сплошные безопасные рисунки (божьи коровки, машины, солнце, трава, медицинские и математические кресты) защищены от ложных срабатываний. При блокировке восстанавливается предыдущий чистый кадр с сохранением истории Undo/Redo.

## Быстрый старт

### Требования
- **Node.js** 20 или новее
- **npm** 10 или новее

```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```

## Тестирование

Тестовый набор проекта покрывает 52 комплексных сценария:
- **История (Undo / Redo)**: единичные шаги, обрезка альтернативных веток при рисовании после отмены.
- **Транзакции выделения**: перемещение, масштабирование, отмена без пустых промежуточных состояний.
- **Изоляция кадров**: гарантия отсутствия утечки объектов между кадрами при переключении или проигрывании.
- **Персистентность и IndexedDB**: атомарность записей, валидация структуры, откат при превышении квоты, сохранение очередей и корректная миграция устаревших данных `localStorage`.
- **Фильтр контента**: пропуск безопасных цветных рисунков, божьих коровок, синих и ортогональных крестов; блокировка агрессивных красно-чёрных символов и хаотичной зачеркивающей штриховки.
- **Импорт и экспорт**: валидация типов файлов, защита от гигантских разрешений, пропорциональное масштабирование (aspect fit), контракт скачивания PNG и прогресс GIF.
- **Геометрия и алгоритмы**: масштабирование клиентских координат холста, сопоставление шрифта DOM-инпута, распознавание замкнутых контуров (Smart Shape).

## Доступность и мобильная поддержка

- Полная поддержка сенсорных устройств (Touch Events / Pointer Events) с защитой от случайного скролла при рисовании.
- Адаптивная верстка под экраны 360px, 390px, планшеты и десктоп.
- На мобильных экранах панель параметров сворачивается в компактную шторку (drawer).
- Все кнопки без текста снабжены атрибутами `aria-label`.
- Модальные окна оформлены с семантикой `role="dialog"` и закрываются по клавише `Escape`.
- Видимый контур клавиатурного фокуса (`:focus-visible`).
- Поддержка горячих клавиш: `Ctrl/Cmd+Z` (Undo), `Ctrl/Cmd+Shift+Z` / `Ctrl+Y` (Redo), `Escape` (отмена активного действия или закрытие панелей).
